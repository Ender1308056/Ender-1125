## 玩法要点（归档时状态）

- BPM 60–200 可调；短按判定频率支持一分音符／二分音符／四分音符／八分音符，判定窗口随频率自动收紧。
- 短按为三角处单击方向键；长按为按住方向键直到虚线末端的结束三角，起止三角与虚线同色，命中后一起变绿。
- 漏判时角色继续沿道路前进，判定点飘出 MISS／BREAK 动画，但断连击、不计分。
- 道路按 2/4/6/8 小节随机拐弯，只取垂直方向，禁止 180° 掉头；主线不自交，分岔支路为死路且无汇入。
- 长按结束拍不再排短按，避免三角重叠与必 miss。
- 键位支持 WASD 与方向键，可切换；含节拍器、判定轨道、得分与准确率 HUD。
- 美术资产为程序化占位；将对应 PNG 放入 `assets/` 即自动替换。
